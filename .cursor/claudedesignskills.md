# Connected: Claude Design Skillstack

This workspace is connected to [shannonjlove/claudedesignskills](https://github.com/shannonjlove/claudedesignskills).

That repository is a marketplace of 22 design/3D/animation skills (Three.js, GSAP, React Three Fiber, Framer Motion, Babylon.js, and related tools). Cursor copies live in `~/.cursor/plugins/local/<plugin-name>/`.

## Install or refresh

From the Stash repo root:

```bash
./scripts/install-claudedesignskills.sh
```

The script clones or updates `https://github.com/shannonjlove/claudedesignskills.git` and installs each individual plugin for Cursor.

## When to use

Load the matching plugin skill before 3D, animation, scroll, or interactive web work. The catalog skill `claude-design-skillstack` lists every plugin and when it triggers.
