# Claude Design Skillstack

Connected marketplace: https://github.com/shannonjlove/claudedesignskills

Install or refresh local Cursor plugins:

```bash
./scripts/install-claudedesignskills.sh
```

Plugins install to `~/.cursor/plugins/local/<plugin-name>/`. Load the matching skill before implementing 3D, animation, or interactive web work.

## Plugins

- **aframe-webxr** — A-Frame WebXR, VR/AR, HTML entity-component 3D
- **animated-component-libraries** — Magic UI and React Bits animated components
- **animejs** — Anime.js timelines, SVG morphing, stagger
- **babylonjs-engine** — Babylon.js scenes, physics, PBR
- **barba-js** — Barba.js page transitions
- **blender-web-pipeline** — Blender to glTF/web export
- **gsap-scrolltrigger** — GSAP animation and ScrollTrigger
- **lightweight-3d-effects** — Zdog, Vanta.js, Vanilla Tilt
- **locomotive-scroll** — Smooth scroll and parallax
- **lottie-animations** — Lottie / After Effects JSON
- **modern-web-design** — 2024–2025 web design patterns
- **motion-framer** — Framer Motion / Motion for React
- **pixijs-2d** — PixiJS 2D WebGL rendering
- **playcanvas-engine** — PlayCanvas game engine
- **react-spring-physics** — React Spring physics animation
- **react-three-fiber** — React Three Fiber declarative 3D
- **rive-interactive** — Rive state-machine animation
- **scroll-reveal-libraries** — AOS scroll reveals
- **spline-interactive** — Spline visual 3D
- **substance-3d-texturing** — Substance 3D Painter for web
- **threejs-webgl** — Three.js WebGL/WebGPU
- **web3d-integration-patterns** — Combining 3D and animation libraries
